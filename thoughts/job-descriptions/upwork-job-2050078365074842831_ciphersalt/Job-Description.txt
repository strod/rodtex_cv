Section 4: Data Strategy & Flow
The Lean POC relies on a three-tier data structure that must be unified into a single "Join" engine:
Direct Data: Raw SQL exports pulled directly from Amazon Marketing Cloud (AMC) (e.g., Impressions, Deterministic Reach, Conversions).
Derived Data: Metrics calculated from raw AMC data (e.g., Path Depth, Revenue Velocity, New-to-Brand rates).
Synthesized Data: Proxy data manually inserted into the CSV to represent non-digital metrics
Requirement: CipherSalt Inc. will provide the AMC access, but the vendor is expected to navigate the AMC environment, execute the necessary SQL queries, and perform data exports without oversight or technical direction.
